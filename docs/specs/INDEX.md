## Plugin Critical Flows (Current Map)
1. Breakpoint-scoped rule editing (`mottoStyler.css.<breakpoint>`).
2. Shared inner-selector definitions with per-breakpoint rule payloads.
3. Local and CPT class workflows (`id` primary linkage, `slug` repair fallback).
4. Editor/frontend style parity with configured bucket order and derived layout rules.
5. Clear-list and reset-to-defaults behavior; auto-apply defaults on pristine insert still pending.

## Spec Hygiene Rules
- Every behavior-changing PR must reference at least one spec in this index.
- If scope changes during implementation, update spec before code merge.
- Temporary compatibility layers must include explicit removal criteria and target phase.
