# PR Checklist (Spec-Driven Pilot)

## Required
- [ ] This PR references one spec file under `docs/specs/`.
- [ ] Changes are mapped to spec requirements (in PR description).
- [ ] Acceptance criteria in the spec are explicitly marked as covered.
- [ ] Tests/checks from the spec test plan were run.

## Evidence
- [ ] Test output summary included in PR description.
- [ ] Any temporary compatibility layer is labeled with removal condition.

## Guardrails
- [ ] No behavior changes outside spec scope.
- [ ] If scope changed, spec was updated first.
